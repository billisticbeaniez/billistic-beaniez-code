# Billistic Beaniez — FLL Robot Code

This repository contains the robot code used by the Billistic Beaniez FIRST LEGO League team.

## Robot Code

All of our FLL robot programs are stored in the `Robot` folder.

The folder contains our different competition runs and programs, including:

* `Run 1`
* `Run 2`
* `Run 3`
* `Run 4`
* Additional runs and test programs

Each run contains the code used to control the robot and complete our planned FLL missions.

## How We Program

Our robot code is developed through testing and iteration. We create a run, test it on the FLL table, identify problems, and then modify the program to improve reliability and performance.

The different runs in this repository represent different versions of our robot programming.

## Robot Development

Our programming is designed around:

* Accurate movement
* Reliable mission execution
* Consistent positioning
* Sensor use
* Motor control
* Attachments
* Efficient runs

Programs may change as we improve the robot, attachments, and strategy throughout the season.

## Team

Billistic Beaniez is a community FIRST LEGO League team.

This repository is maintained to document and share our FLL robot programming and development.
